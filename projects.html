AI ROS based Robotic arm

Designed and developed a 6-DOF ROS 2 robotic arm that autonomously sorts objects by shape and color using computer vision and machine learning. The system leveraged an NVIDIA Jetson Nano for real-time AI inference, integrated AX-12A Dynamixel servos for precise manipulation, and utilized modular ROS 2 nodes for perception, motion control, and actuation, demonstrating the seamless integration of robotics, embedded systems, and intelligent automation.

  • Role: Lead designer
  • Tools: SolidWorks, Arduino, OpenCV, ROS

Smart water meter

Designed and developed a smart IoT-based water metering system for real-time consumption monitoring and remote data transmission using GSM and LoRa communication. The solution featured a custom PCB integrating a flow sensor, battery management system, and display interface, with embedded firmware handling sensor calibration, data acquisition, and wireless communication. The system enabled accurate water usage tracking, leak detection, and intelligent resource management through real-time data logging and alerts.

Shift Register Integration with Veri Sens Vision System

Designed and implemented a machine vision interface using a Baumer VeriSens smart camera and a custom shift register circuit for automated inspection and sorting. The system was integrated with PLC logic to synchronize object detection with actuator control, improving communication, timing precision, detection accuracy, and overall automation reliability.
